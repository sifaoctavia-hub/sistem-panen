# Sistem Pencatatan Hasil Panen

## Deskripsi
Program sederhana untuk mencatat hasil panen dan menghitung total harga berdasarkan jumlah hasil panen dan harga per kilogram. Program ini juga memiliki fitur perhitungan diskon.

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Buka terminal pada folder proyek.
3. Jalankan perintah:

```bash
python panen.py
